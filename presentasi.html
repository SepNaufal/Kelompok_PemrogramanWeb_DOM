📖 Apa itu DOM?

DOM (Document Object Model) adalah representasi terstruktur dari dokumen HTML dalam bentuk pohon objek (tree) yang memungkinkan JavaScript mengakses dan memanipulasi halaman web secara dinamis.

DOM menjadi jembatan antara HTML (struktur) dan JavaScript (logika), sehingga halaman web bisa berubah tanpa harus di-reload.

🔍 1. Seleksi Elemen

Langkah pertama dalam DOM — memilih elemen yang ingin dimanipulasi

// Mengambil form berdasarkan ID
const form = document.getElementById("form-tambah");

// Mengambil semua tombol filter
const buttons = document.querySelectorAll(".filter-btn");

// Mengambil satu elemen dengan CSS selector
const input = document.querySelector("#input-tugas");
Metode Hasil Contoh di TaskMate
getElementById() 1 elemen (by ID) Mengambil form, input, daftar
querySelector() 1 elemen pertama Mengambil item tugas tertentu
querySelectorAll() Semua elemen (NodeList) Mengambil semua tombol filter

✏️ 2. Manipulasi Konten

Mengubah isi teks dan atribut elemen HTML

textContent

// Update angka statistik
statTotal.textContent = total;

// Update label progress
label.textContent = persen + "%";

Mengubah teks tanpa merender HTML

innerHTML

// Reset daftar tugas
container.innerHTML = "";

// Render ulang isi container
container.innerHTML = htmlBaru;

Menyisipkan konten HTML

📌 .value digunakan untuk mengambil/mengubah nilai input: inputTugas.value

➕ 3. Membuat & Menghapus Elemen

Menambahkan elemen baru ke DOM dan menghapus yang tidak diperlukan

// MEMBUAT elemen baru
const li = document.createElement("li");
li.className = "tugas-item";

// MENYUSUN child elements
const checkbox = document.createElement("div");
li.appendChild(checkbox);

// MENAMBAHKAN ke daftar
container.appendChild(li);

// MENGHAPUS elemen
elemen.remove();

🎨 4. Manipulasi Style & Class

Mengubah tampilan elemen secara dinamis melalui JavaScript

element.classList

// Tandai selesai
li.classList.add("selesai");

// Toggle filter aktif
btn.classList.remove("active");
this.classList.add("active");

// Tampilkan modal
modal.classList.add("tampil");

element.style

// Ubah lebar progress bar
fill.style.width = persen + "%";

// Tampilkan/sembunyikan tombol
btn.style.display = "none";
btn.style.display = "inline-block";

⚠️ Gunakan camelCase:
background-color → backgroundColor

⚡ 5. Event Handling

Menangani interaksi pengguna menggunakan addEventListener()

// Event: submit form (tambah tugas)
form.addEventListener("submit", function(e) {
  e.preventDefault();  // Cegah reload halaman
  tambahTugas();
});

// Event: klik checkbox (tandai selesai)
checkbox.addEventListener("click", function() {
  toggleSelesai(tugas.id);
});

// Event: input pencarian (real-time)
inputCari.addEventListener("input", function() {
  renderTugas();
});

⚡ Jenis Event di TaskMate

Event Kapan Terjadi Digunakan Untuk
submit Form di-submit Menambahkan tugas baru
click Elemen diklik Checkbox, tombol edit/hapus, filter
input Nilai input berubah Pencarian tugas real-time
keydown Tombol keyboard ditekan Tekan Escape → tutup modal

📌 preventDefault() mencegah aksi default browser. Contoh: mencegah form melakukan reload halaman saat di-submit.

🌳 6. DOM Traversal

Bernavigasi antar elemen di DOM Tree

// Naik ke parent — saat klik tombol hapus
const li = button.parentElement;  // tombol → <li>

// Turun ke children — hitung jumlah tugas
const count = daftar.children.length;

// Mengambil anak terakhir
const last = container.lastElementChild;

🏷️ 7. setAttribute & getAttribute

Mengatur dan membaca atribut HTML dari JavaScript

// Menyimpan ID tugas sebagai atribut data
li.setAttribute("data-id", tugas.id);

// Membaca atribut data-filter dari tombol
const filter = this.getAttribute("data-filter");

// Mengambil elemen berdasarkan atribut
const item = document.querySelector(
  '.tugas-item[data-id="5"]'
);

📌 data-* attributes memungkinkan kita menyimpan data kustom pada elemen HTML yang bisa diakses JavaScript.
