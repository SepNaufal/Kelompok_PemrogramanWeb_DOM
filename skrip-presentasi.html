📖 Slide 2: Apa itu DOM?

SLIDE 02

"Pertama-tama, apa sebenarnya DOM itu? Secara sederhana, DOM (Document Object Model) adalah representasi terstruktur dari kode HTML kita yang dibentuk oleh browser menjadi pohon objek (tree of objects)."

"Kenapa DOM ini sangat penting? Karena DOM menjadi jembatan penghubung antara struktur HTML dan logika JavaScript. Berkat DOM, JavaScript memiliki kekuatan untuk membaca, mengubah teks, mengganti warna/style, sampai menambah dan menghapus komponen halaman secara langsung tanpa perlu me-reload halaman web."

📌 Poin Kunci yang Harus Disampaikan:
  • DOM membuat web menjadi dinamis dan interaktif.
  • DOM adalah jembatan antara HTML dan JavaScript.
  • Perubahan terjadi instan tanpa refresh browser.
💡 Jika ditanya dosen: "Kapan DOM dibuat?"
Jawab: "DOM dibangun secara otomatis oleh browser tepat saat browser mem-parsing atau membaca file HTML."

🌳 Slide 3: Struktur DOM Tree

SLIDE 03

"Ketika browser membaca file HTML kita, browser akan menyusunnya menjadi sebuah pohon terbalik atau DOM Tree."

"Bisa kita lihat di diagram slide: Pada posisi paling puncak terdapat objek document sebagai akar (root). Di bawahnya terdapat elemen <html> yang bercabang menjadi dua anak utama, yaitu <head> dan <body>."

"Di aplikasi TaskMate kita, di dalam <body> terdapat header, form input, dan list <ul>. Setiap tag HTML menjadi satu cabang atau titik yang kita sebut Node. Karena tersusun rapi seperti silsilah keluarga, JavaScript bisa dengan mudah menunjuk bagian mana yang mau diubah."

📌 Poin Kunci yang Harus Disampaikan:
  • Hirarki: Root (document) → html → head/body → elemen anak.
  • Hubungan antar elemen: Parent (induk), Child (anak), Sibling (saudara).

🔤 Slide 4: Jenis-Jenis Node

SLIDE 04

"Di dalam DOM Tree, setiap komponen disebut Node. Ada 4 tipe node utama yang wajib kita ketahui:"

"1. Document Node: Titik paling awal/puncak dari seluruh dokumen web.
2. Element Node: Tag-tag HTML seperti <div>, <button>, <input>, dan <li>.
3. Text Node: Teks aktual di dalam tag, misalnya tulisan 'TaskMate' di dalam judul.
4. Attribute Node: Informasi pelengkap pada elemen, seperti id, class, atau type."

"Dalam pembuatan web, Element Node dan Text Node adalah yang paling sering kita manipulasi menggunakan JavaScript."

📌 Poin Kunci yang Harus Disampaikan:
  • Bedakan antara Element Node (wadahnya) dan Text Node (isinya).

✅ Slide 5: Studi Kasus (TaskMate)

SLIDE 05

"Untuk membuktikan implementasi konsep-konsep tersebut, kami membuat TaskMate."

"TaskMate adalah aplikasi manajemen tugas harian yang memiliki 6 fitur utama: Menambah tugas baru, Menandai tugas selesai, Mengedit nama dan prioritas tugas via modal, Menghapus tugas dengan animasi, Pencarian & filter real-time, serta Counter statistik & progress bar yang bergerak otomatis."

"Seluruh fungsionalitas ini 100% menggunakan DOM JavaScript murni tanpa bantuan library atau framework tambahan."

🔍 Slide 6: 1. Seleksi Elemen

SLIDE 06

"Langkah pertama sebelum kita bisa mengubah apapun di layar adalah memilih elemen target."

"Di JavaScript terdapat metode seleksi populer:"

"Pertama, getElementById('form-tambah'). Ini kita gunakan untuk mengambil elemen yang punya ID unik, seperti form dan kolom input."

"Kedua, querySelector() dan querySelectorAll(). Metode ini sangat fleksibel karena memakai format CSS Selector. Di TaskMate, kita memakai querySelectorAll('.filter-btn') untuk mengambil sekaligus ketiga tombol filter (Semua, Belum, Selesai) dalam bentuk NodeList."

📌 Poin Kunci yang Harus Disampaikan:
  • getElementById → Sangat cepat, khusus ID unik.
  • querySelector → Elemen pertama yang cocok dengan CSS selector.
  • querySelectorAll → Mengembalikan semua elemen yang cocok (NodeList).

✏️ Slide 7: 2. Manipulasi Konten

SLIDE 07

"Setelah elemen berhasil kita seleksi, kita bisa memanipulasi isinya. Ada dua properti utama:"

"1. textContent: Digunakan untuk mengubah teks murni. Di TaskMate, kita gunakan untuk memperbarui angka total tugas, jumlah tugas selesai, dan label persentase."

"2. innerHTML: Mampu mem-parsing tag HTML. Kita gunakan container.innerHTML = '' untuk mengosongkan daftar sebelum me-render data yang baru."

"Selain itu, untuk elemen input form, kita menggunakan properti .value untuk membaca apa yang diketikkan user atau mengosongkannya kembali setelah tombol Tambah ditekan."

📌 Poin Kunci yang Harus Disampaikan:
  • Gunakan textContent untuk keamanan dari serangan XSS saat menampilkan teks biasa.
  • Gunakan .value khusus elemen interaktif (input, textarea, select).

➕ Slide 8: 3. Membuat & Menghapus Elemen

SLIDE 08

"Fitur utama dari To-Do List adalah menambah dan menghapus baris tugas. Ini melibatkan metode DOM yang sangat krusial:"

"1. document.createElement('li'): Membuat elemen tag HTML baru di memori browser."
2. Kita berikan class, atribut, dan teks pada elemen baru tersebut.
3. container.appendChild(li): Memasukkan elemen baru tersebut ke dalam parent <ul> sehingga langsung tampil di layar."

"Sedangkan untuk menghapus, kita cukup memanggil elemen.remove() sehingga elemen tersebut dicopot seketika dari DOM Tree."

📌 Poin Kunci yang Harus Disampaikan:
  • Alur: createElement() → atur isi → appendChild().
  • Penghapusan: remove() untuk mencabut node dari pohon.

🎨 Slide 9: 4. Manipulasi Style & Class

SLIDE 09

"Untuk memberikan efek visual yang responsif, DOM menyediakan manipulasi styling:"

"Pertama melalui classList. Ini praktik terbaik untuk menambah atau mencopot class CSS. Contohnya, saat user mengklik checkbox, JavaScript mengeksekusi li.classList.add('selesai'). Seketika CSS akan memberikan coretan teks dan menurunkan opasitas."

"Kedua melalui element.style. Di TaskMate, kita pakai untuk progress bar dinamis: progressFill.style.width = persen + '%'. Panjang barnya langsung memanjang atau memendek secara mulus mengikuti kalkulasi persentase."

📌 Poin Kunci yang Harus Disampaikan:
  • classList.add/remove/toggle memisahkan logika JS dan style CSS.
  • element.style untuk nilai dinamis yang berubah-ubah (seperti persentase bar).
  • Ingat aturan camelCase (misal: backgroundColor).

⚡ Slide 10: 5. Event Handling

SLIDE 10

"Aplikasi web tidak akan bisa berinteraksi tanpa adanya Event Handling. Event adalah aksi yang dilakukan pengguna, seperti mengklik tombol, mengetik, atau menekan tombol keyboard."

"Kita menggunakan addEventListener(). Sebagai contoh pada form penambahan tugas, kita mendengarkan event 'submit'."

"Sangat penting di sini kita memanggil e.preventDefault(). Mengapa? Karena tabiat default form HTML ketika disubmit adalah me-refresh seluruh halaman. Dengan preventDefault(), reload tersebut kita hentikan agar data dimasukkan secara mulus tanpa kedip."

📌 Poin Kunci yang Harus Disampaikan:
  • Fungsi addEventListener untuk menangkap aksi pengguna.
  • Pentingnya preventDefault() pada submit form.

⚡ Slide 11: Jenis Event di TaskMate

SLIDE 11

"Berikut adalah ringkasan event yang kami terapkan di aplikasi TaskMate:"

"1. submit: Pada form saat user menambah tugas.
2. click: Pada checkbox, tombol filter, tombol edit, dan tombol hapus.
3. input: Pada kolom pencarian. Event ini langsung mendeteksi setiap ketikan karakter sehingga filter pencarian berjalan real-time.
4. keydown: Menangkap tombol keyboard. Kami pasang untuk tombol 'Escape' agar user bisa menutup pop-up modal edit dengan praktis."

🌳 Slide 12: 6. DOM Traversal

SLIDE 12

"DOM Traversal adalah kemampuan berpindah dari satu elemen ke elemen lainnya berdasarkan relasi pohonnya."

"Contoh nyatanya: Saat user menekan tombol icon sampah di baris tugas, tombol itu memanggil event. Melalui button.parentElement, JavaScript dapat langsung mengetahui elemen <li> induknya untuk kemudian dihapus."

"Contoh lain, kita menggunakan parent.children.length untuk menghitung berapa banyak tugas yang sedang aktif di dalam kontainer."

📌 Poin Kunci yang Harus Disampaikan:
  • Navigasi ke atas: parentElement.
  • Navigasi ke bawah: children, firstElementChild.

🏷️ Slide 13: 7. setAttribute & getAttribute

SLIDE 13

"Dalam mengelola data dinamis, kita sering butuh menyimpan ID unik pada elemen HTML. Kami menggunakan HTML5 Data Attributes."

"Saat baris tugas dibuat, kita pasang atribut li.setAttribute('data-id', tugas.id). Sehingga ketika tombol edit atau hapus diklik, program dengan mudah membaca getAttribute('data-id') untuk mencocokkan tugas mana di database array yang harus dimodifikasi."

🗺️ Slide 14: Peta Konsep DOM di TaskMate

SLIDE 14

"Tabel pada slide 14 ini merangkum keterkaitan utuh antara fitur aplikasi dan konsep DOM:"

"Ketika menambah tugas, DOM yang bekerja adalah createElement, appendChild, dan preventDefault. Ketika menandai selesai, yang bekerja adalah classList. Ketika pencarian, yang bekerja adalah input event dan innerHTML. Dan ketika menghitung progres, yang bekerja adalah textContent dan style.width."

"Tabel ini membuktikan bahwa sebuah aplikasi fungsional yang sederhana sekalipun terbangun dari kombinasi berbagai metode DOM."

❓ Lembar Jawaban Cepat Sesi Tanya Jawab (Q&A)

CHEAT SHEET

Q1: Apa bedanya file HTML statis dengan DOM?

Jawaban: "File HTML adalah teks kode mentah yang tersimpan di disk. Sedangkan DOM adalah objek hidup di memori browser yang dihasilkan dari proses parsing HTML tersebut. JavaScript tidak bisa mengubah file HTML asli di server, tapi JavaScript bisa mengubah DOM di browser user."

Q2: Kenapa lebih memilih textContent dibanding innerHTML untuk menampilkan data teks?

Jawaban: "Karena aspek keamanan. innerHTML akan mengeksekusi tag HTML apa saja termasuk tag <script> yang rawan disisipi kode berbahaya (Cross-Site Scripting / XSS). Sedangkan textContent murni memperlakukan input sebagai teks string biasa, sehingga jauh lebih aman dan performanya lebih cepat."

Q3: Apa fungsi e.preventDefault() pada form?

Jawaban: "Secara default saat form HTML disubmit, browser akan mengirimkan request HTTP GET/POST dan me-refresh seluruh halaman web. Karena kita membuat Single Page Application sederhana, kita mencegah reload tersebut menggunakan preventDefault() agar eksekusi data ditangani langsung oleh JavaScript tanpa reload."

Q4: Mengapa menggunakan classList daripada langsung mengubah element.style?

Jawaban: "Prinsip Separation of Concerns (Pemisahan Tugas). Lebih baik semua urusan desain/style disimpan di file CSS, dan JavaScript hanya bertugas memasang atau mencabut nama class-nya melalui classList. Kecuali untuk nilai dinamis yang berubah-ubah secara matematis seperti panjang progress bar."
